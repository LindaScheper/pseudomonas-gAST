# Genotypic AST for *Pseudomonas aeruginosa* — Analysis Pipeline

This repository contains the analysis code and derived input data for the
manuscript on genotypic antimicrobial susceptibility testing (gAST) in
*P. aeruginosa*, covering ciprofloxacin (CIP), ceftazidime (CAZ), meropenem
(MEM) and tobramycin (TOB). Gentamicin (GEN) is intentionally **not** part
of this analysis.

The folder names above are a suggestion; every script in `derived/` and
`consolidate/` uses **plain relative filenames** (e.g. `open("buildcache.pkl")`)
rather than `paths.py`, so in practice **all scripts and all data files must
be run from the same flat working directory**. Only `paths.py`,
`13\\\_dedup\\\_marker.py`, `14\\\_mexxy\\\_traeger.py`, `15\\\_mechanismusklassen.py`,
`17\\\_drei\\\_zustaende.py`, `01\\\_konfidenzintervalle.py`, `03\\\_filterkosten.py`,
`04\\\_schwelle\\\_1komma4.py`, `02\\\_enzym\\\_rule\\\_in.py`, `00\\\_amr\\\_einlesen.py` and all `figures/\\\*.py`
scripts use `paths.DATA` / `paths.OUT`. If you keep everything in one
directory and run all scripts from there, this inconsistency does not
matter in practice.

## Data

All data files in `data/` are filtered to *P. aeruginosa* isolates only
and use pseudonymised patient identifiers (`patient\\\_xxxxxxxx`). Hospital
codes (`hospital` column in `sample\\\_table.pkl`) are retained under the
project's ethics approval.

Raw sequencing data (FASTQ / assemblies) are **not** part of this
repository; see the manuscript's Data Availability statement for the
corresponding ENA/NCBI accession numbers.

`hgvs\\\_sets.pkl` (frameshift/stop/insertion carrier sets derived from HGVS
mutation notation) is **not** provided as a file — it is regenerated by
`02\\\_hgvs\\\_sets.py` from `v3\\\_mut.pkl` (see step 1 below).

## Execution order

Run everything from one working directory that also contains the files
from `data/`. Some scripts must be called **repeatedly** until they print
`"nichts offen"` / `"alle Blaetter gelesen"` — this reflects a checkpointed,
time-limited original run and is preserved here for reproducibility.

### 1. Raw table ingestion *(required — produces `v3\\\_mut.pkl`, `v3\\\_pheno.pkl` and `hgvs\\\_sets.pkl`, all of which are hard dependencies of later steps)*
```

python 01\\\_tabelle\\\_einlesen.py     # run repeatedly until "alle Blaetter gelesen"

python 03\\\_zusammenfuehren.py      # -> v3\\\_mut.pkl, v3\\\_pheno.pkl

python 02\\\_hgvs\\\_sets.py            # -> hgvs\\\_sets.pkl (needs v3\\\_mut.pkl)

```

### 2. Core cache
```

python 04\\\_buildcache.py           # -> buildcache.pkl, corebits.pkl

\&#x20;                                  #    (internally runs 03\\\_core.py via exec)

python final\\\_prot.py              # run 12x (4 antibiotics x 3 modes) until "nichts offen"

\&#x20;                                  # -> final\\\_all.json

python 00\\\_amr\\\_einlesen.py	# -> v3\\\_amr.pkl

```

### 3. Derived analyses
```

python 07\\\_elongation.py           # -> elong.json

python 08\\\_rulein.py               # -> rulein\\\_final.json

python 09\\\_spezifitaetsfilter.py   # run 4x (one per antibiotic) until "nichts offen"

\&#x20;                                  # -> spec\\\_off.json

python 10\\\_pumpenmerkmal.py        # -> noprot.json

python 11\\\_mexxy\\\_merkmal.py        # -> tob\\\_xyprot.json

python 12\\\_ecoff\\\_endpunkt.py       # run 2x until "nichts offen"

\&#x20;                                  # -> ecoff\\\_mem.json

python 13\\\_dedup\\\_marker.py         # -> dedup\\\_markers.json

python 14\\\_mexxy\\\_traeger.py        # -> stdout only

python 15\\\_mechanismusklassen.py   # -> mech\\\_classes.json

python 17\\\_drei\\\_zustaende.py       # -> drei\\\_zustaende.json

python oprd\\\_cls\\\_bauen.py          # -> oprd\\\_cls.pkl

python pumps.py                   # -> pumps.json

python pumpfig\\\_data.py            # -> pumpfig.json (needs pumps.json, porin\\\_rescue.json)

```

### 4. Consolidation
```

python 02\\\_specratio.py            # -> specratio.pkl, specratio.json (needs oprd\\\_cls.pkl)

python 01\\\_figdata.py              # -> figdata.pkl (needs buildcache.pkl, corebits.pkl,

\&#x20;                                  #    v3\\\_mut.pkl, final\\\_all.json)

```

### 5. Checks
```

python 02\\\_enzym\\\_rule\\\_in.py        # -> rulein\\\_v2.json (needs final\\\_all.json)

python 01\\\_konfidenzintervalle.py  # -> ci\\\_kern.json (needs final\\\_all.json, spec\\\_off.json,

\&#x20;                                  #    noprot.json, tob\\\_xyprot.json)

python 03\\\_filterkosten.py         # -> filterkosten.json (needs specratio.pkl)

python 04\\\_schwelle\\\_1komma4.py     # -> stdout only (needs specratio.pkl, specratio.json)

```

### 6. Figures
```

python fig1\\\_loss\\\_of\\\_function.py   # -> Figure1\\\_loss\\\_of\\\_function.png/.pdf

python fig2\\\_specificity.py        # -> Figure2\\\_specificity.png/.pdf

python fig3\\\_mechanism\\\_classes.py  # -> Figure3\\\_mechanism\\\_classes.png/.pdf

python fig4\\\_pumps.py              # -> Figure4\\\_pumps.png/.pdf

python fig5\\\_mic\\\_detection.py      # -> Figure5\\\_mic\\\_detection.png/.pdf

python fig6\\\_reporting.py          # -> Figure6\\\_deduplication.png/.pdf  (filename, see note below)

python figS1\\\_cohort.py            # -> SupplementaryFigure1\\\_cohort.png/.pdf

python figS2\\\_polarisation.py      # -> SupplementaryFigure2\\\_polarisation.png/.pdf

python figS3\\\_trajektorien.py      # -> SupplementaryFigure3\\\_trajectories.png/.pdf

python figS4\\\_deduplication.py     # -> SupplementaryFigure4\\\_deduplication.png/.pdf

```

All figure scripts read from `figdata.pkl` and/or the JSON files produced
in steps 3–5, plus `buildcache.pkl` where noted in the script itself.
